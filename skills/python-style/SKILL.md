# Python 项目约束

本 skill 只补充项目约束，不重复 Python 官方风格或模型已掌握的通用惯用法。

## 1. 公共接口

- 公共函数、方法和异步方法必须有参数与返回值类型标注。
- 公共接口的 docstring 说明行为、参数、返回值和可预期异常；私有辅助函数不强制套模板。
- 模块对外导出路径应稳定，调用方不得依赖内部实现文件。

## 2. 资源与配置

- 文件、数据库会话、锁、网络响应等资源必须有明确的关闭或释放路径；优先使用上下文管理器。
- 密钥、连接串、模型配置和环境差异不得硬编码，统一从项目既有配置入口读取。
- 外部 I/O 必须设置超时；重试、限流和降级遵循业务模块已有机制，不在业务函数中随意复制。

## 3. 异常边界

- 在能处理异常的边界捕获具体异常；不要用裸 `except`，也不要为了继续执行而吞掉异常。
- 底层模块保留可诊断的异常上下文；接口层或任务边界再转换为项目约定的错误响应或失败状态。
- 事务必须保证提交、回滚和资源释放的一致性；不要在事务外静默修改部分结果。

## 4. 注释与验证

- 注释只解释代码无法表达的决策原因，默认使用项目规定的语言；不为显而易见的语句添加注释。
- 修改后至少运行触及模块的测试、类型检查或 lint；没有自动化检查时，说明实际验证范围。
